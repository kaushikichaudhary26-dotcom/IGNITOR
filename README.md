# Ignitor Fitness — Single Page Demo

This is a single-file demo for Ignitor Fitness, styled in a Cult.fit-inspired dark theme.

How to view:

Open `index.html` in a browser. No build step required; it uses Tailwind CDN and Alpine.js.

Repository structure (recommended):

- `index.html` — Single-page app
- `assets/` — Put `logo.png`, `hero.jpg`, and any other images/videos here
- `README.md` — This file
- `.gitignore` — Ignore OS and node artifacts

Notes:
- Place the official logo at `assets/logo.png` and the chosen hero image at `assets/hero.jpg`.
- Replace placeholder images/videos with real media from the gym's Instagram.
- To deploy, serve `index.html` via any static host (Netlify, Vercel, GitHub Pages).
